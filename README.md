# Slip Three

Ten recordings, released one a week on Tuesdays at 03:00 UTC, alongside the
files they are about.

Site: https://st88openocean.github.io/slip-three
Feed: https://st88openocean.github.io/slip-three/podcast.xml

Every published file has its SHA-256 listed at `/archive/`, and the machine
readable inventory is at `/archive/manifest.json`. If a digest does not match,
the copy has been altered. Mirroring is encouraged.

Slip Three is a serialised audio work. Every organisation, vessel, station,
port, operator, callsign, case number and event date in it is invented. See
`provenance.txt`.

Contact: slipthree@proton.me
